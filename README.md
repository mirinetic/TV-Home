# TV Home

TV 홈 화면 UI 프로토타입(웹)을 구글 TV · 안드로이드 TV에서 실제로 돌려 보는 테스트베드 앱.

- 일반 앱으로 설치되어 TV 앱 목록에 **TV Home**으로 표시돼요 (홈 런처를 바꾸지 않음).
- 화면은 `web/`의 React 프로토타입을 그대로 써요. 리모컨 방향키 · OK는 그대로, **뒤로**는 Esc로 전달돼요.
- 앱 줄의 타일(넷플릭스, 유튜브, 프라임 비디오, 디즈니+, 애플 TV, HBO Max, Hulu 등)은 TV에 그 앱이 있으면 **실제 앱을 열고**, 없으면 프로토타입의 앱 상세 화면을 보여 줘요.
- 콘텐츠 카드에 포커스가 가면 카드 아래에 **서비스 아이콘 · 제목 | 종류 · 연도**가 나와요. '오늘의 TOP 10' 줄은 순위 숫자를 카드 왼쪽에 크게 보여 줘요.
- 콘텐츠 카드에서 OK를 누르면 그 작품의 상세 화면(아트, 서비스, 종류 · 연도, 줄거리)이 열리고, **〈서비스〉에서 보기**를 누르면 그 TV 앱을 열어요.
- 기본 조작은 **리모컨(D-pad) 모드**예요. 시뮬레이터 설정에서 마우스도 받는 하이브리드 모드로 바꿀 수 있어요.
- 개인 테스트용 사이드로드 앱이에요. 스토어 배포용이 아니에요.

## 상단 탭 화면

상단 가운데 탭에서 ▼를 누르면 각 탭 화면으로 들어가요. 방향키로 이동하고 OK로 실행, 맨 윗줄에서 ▲ 또는 뒤로를 누르면 상단 메뉴로 돌아가요.

- **라이브**: 가상 채널 8개(코브 뉴스24, 무비 플러스, 스포츠 원 …)의 지금 방송 미리보기와 2시간 편성표. 지금 시각 선(빨간 선)과 진행 바가 실제 시간에 맞춰 움직여요. 방송 중인 프로그램에서 OK는 TV의 라이브 TV 앱을 열고, 예정 프로그램에서 OK는 시청 예약/취소예요.
- **게임**: 추천 게임 배너와 '이어서 하기(진행률)', '클라우드 게임 인기', '리모컨으로 가볍게' 줄. 게임은 모두 가상이고, 실행은 안내만 해요.
- **아트**: 저작권이 끝난 명화 16점(고흐, 모네, 르누아르, 쇠라, 페르메이르, 클림트, 칸딘스키, 호쿠사이, 히로시게, 정선 등)을 사조별 줄로 보여 줘요. OK를 누르면 전체 화면으로 크게 보고, ◀ ▶로 같은 줄의 다음 작품, OK로 작품 정보, 뒤로로 닫아요. 이미지는 위키미디어 커먼즈의 퍼블릭 도메인 파일이에요.
- **앱스**: TV에 실제로 설치된 앱을 배너와 함께 보여 주고, OK로 바로 열어요 (브라우저 미리보기에서는 샘플 앱).

## 시뮬레이터 설정 (옵션)

- 여는 방법: TV에서는 **뒤로 버튼을 길게** 누르기 (키보드는 `o`, 마우스는 오른쪽 가장자리 탭)
- 리모컨으로 조작: 방향키로 이동, OK로 선택, 뒤로로 닫기
- 항목: 최초 포커스 위치, 인터랙션 모드(D-pad / 하이브리드), GNB 메뉴 순서, 배경 딤, 카드 포커스 스타일, 가상 리모컨, 와이어프레임 뷰, 전원 끄기(끈 뒤에는 OK로 다시 켜기), Apply & Restart

## 업데이트

- 시뮬레이터 설정(뒤로 길게) → **08. 앱 업데이트**에서 **업데이트 확인**을 누르면 새 버전이 있는지 보고, 있으면 **설치**로 내려받아 TV의 설치 확인 창을 열어요. 자동으로 확인하지는 않아요.
- 처음 한 번은 TV가 "출처를 알 수 없는 앱 설치" 허용을 물어요. TV Home을 허용해 주세요.
- 이 기능은 저장소가 **공개**일 때만 동작해요 (`tvhome-latest` 릴리스에서 받아요).

## 받기

`main`에 푸시할 때마다 GitHub Actions가 빌드해서 Releases에 `v1.0.N`으로 올려요. 최신 릴리스의 `TVHome.apk`를 TV에 설치하면 돼요. 같은 개인 키로 서명해서 새 버전을 덮어 설치할 수 있어요.

## 구성

```
web/   React 19 + Vite + Tailwind 프로토타입 (npm run dev 로 브라우저에서 확인)
app/   Kotlin WebView 껍데기 (assets/www 에 web/dist 를 넣어 실행)
```

- 웹 → 앱 연결: `web/src/native.ts` (`TVHomeNative.launchApp(name)`, `hasApp(name)`)
- 타일 이름 → 패키지 매핑: `app/src/main/java/com/mirinetic/tvhome/Apps.kt`
- 이미지는 PNG를 품질 90 WebP로 바꿔 넣었어요 (106.6MB → 14.2MB).

## 로컬에서 보기

```bash
cd web && npm install && npm run dev
```
